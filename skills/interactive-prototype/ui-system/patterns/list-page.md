# Pattern: list-page（列表页）

> 适用：用户管理、订单列表、资源列表、日志列表、记录管理…
> 对应组件：search-form + table + pagination + status-tag + empty + button + modal/drawer

## 页面结构（自上而下）

```
Page Header（页面标题 + 右侧主操作按钮）
  ↓
Search Form（筛选区：2~4 个条件一行，条件多自动换行）
  ↓
Table Card（白底圆角卡片）
  ├─ Toolbar（左：批量操作/新增；右：搜索框）
  ├─ Table（表头 + 表体 + 操作列）
  ├─ Empty（无数据时，表头保留）
  └─ Pagination（总数 + 页尺寸 + 页码）
```

## 规则

| 事项 | 规定 |
|---|---|
| Primary Action | 放两处：Page Header 右侧（全局主操作如「新增」）+ Table Toolbar 左侧。二选一即可，**不要两处重复** |
| 筛选排列 | 条件从宽到窄：状态 → 类别 → 时间 → 关键词；每行 2~4 个；查询/重置按钮放行尾 |
| 时间筛选 | 用两个 date input + 「至」，不要自由设计时间控件 |
| 关键词 | 用带搜索图标的 input（affix），宽度 200-240px |
| Table 操作列 | 最多 3 个文字链接（查看/编辑/删除）；超过 3 个折叠到「更多」下拉 |
| 危险操作 | 删除类操作必须二次确认（Modal confirm），不能直接执行 |
| 状态展示 | 一律用 status-tag 组件（Tag 或圆点状态），禁止自定义颜色 |
| 金额对齐 | 金额/数值列右对齐 + tabular-nums，表头右对齐 |
| 长文本 | 用 ui-ellipsis 截断（max 200px），hover 提示完整值 |
| Empty State | 表格无数据：保留表头，表体放 ui-empty；文案「暂无{对象}」+ 可引导新建 |
| 多选 | 首列表头放全选框，行首复选框；批量操作按钮在 Toolbar 左侧，选中后可用 |
| 分页 | 默认每页 10/20/50；页码不超过 7 个（1 … 5 6 7 … 末页） |

## 行为

- 查询：点击查询按钮 → 模拟筛选（原型可直接 JS 过滤或仅 toast「查询成功」+ 列表不变）
- 重置：恢复默认筛选值
- 行点击：默认无行为；有详情时整行点击进详情（或点「查看」）
- 分页/页尺寸切换：仅更新页码高亮与总数，不追求真实翻页

## 默认方案（不确定时用这个）

Page Header 右侧一个「新增」主按钮 → Search Form（状态 + 关键词两条件）→
Table Card（操作列：查看/编辑/删除）→ Pagination。表格 5~8 行 Mock 数据。
