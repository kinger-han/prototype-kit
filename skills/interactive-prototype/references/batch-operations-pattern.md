# 列表页批量操作原型模式（2026-08-28 未命中批量操作实测，可复用到其他列表页）

## 状态模型（以未命中问题为例）
```
待处理 →(批量/单条补充) 已补充 [终态，badge 链知识详情弹窗]
       →(批量/单条合并) 已合并 [终态，data-main 指向主问题]
       →(批量/单条忽略) 已忽略 [可"恢复待处理"]
```
- **终态设计依据**（用户拍板 2026-08-28）：提交补充/合并触发 Dify 解析不可逆，批量+撤销复杂度不成比例；误操作修正走"编辑知识详情"，不做状态回退
- 恢复待处理**仅对已忽略开放**；选区混状态时确认弹窗提示跳过数

## 页面结构
1. **checkbox 列**（首列，行 class 如 `miss-row-check`）+ 表头 master（`missCheckAll`）
2. **选中操作栏**（默认隐藏，选中>0 显示，浅蓝底 #e6f4ff）：`已选 N 条 ｜ 批量补充 批量合并 批量忽略 恢复待处理 ｜ 取消选择`
3. **跨页全量选中**：全选本页后操作栏出现"选中当前筛选结果全部 M 条"链接（M=常量如 88）；点击置标志位 `_selAllFiltered=true` + 计数切为 M；任意一行取消勾选即失效回退
4. **行状态判定**：`closest('tr')` → 状态列 td 里的 `.badge-status` 文本（去掉 ›）
5. **行状态写入**：统一函数 `batchSetRowState(tr, kind, extra)`——置新 badge + 保留原详情按钮（先取 outerHTML 再回填）+ `missMenuHtml(tr, true/false)` 禁用/恢复更多菜单
6. **确认弹窗带跳过统计**：选区含不适用状态时显示"另有 X 条非待处理，将自动跳过"（黄色警示）；toast 汇总"成功 N 条，跳过 X 条"

## 弹窗要点
- **批量补充**（价值核心：多条相似问题→补一条知识全部关联）：问题清单逐条可勾掉（至少留 1 条）；双 Tab——新建知识（标题默认取首条选中问题）/ 关联已有知识（复用 mergeModal 的搜索卡片单选模式）
- **批量合并**：radio 单选主问题（默认第一条/触发最多），其余标已合并 `data-main=主问题文本`，点击可提示闭环关系
- 提交后 `clearMissSelection()` 清空选区，操作栏隐藏

## ⚠️ 插 checkbox 列的连带改动（高频翻车点）
静态表格加列后，除渲染处的 tds[N] 外，**所有按索引读 td 的辅助函数同步 +1**：
- 参数读取型（如 `missMenuHtml` 读 tds[0..2] 拼 onclick 参数）
- 行查找型（`findXxxByQuestion` 取第一个 td 匹配文本 → 改取第二个）
- 状态写入型（markXxx 的 tds[6]/tds[7] → tds[7]/tds[8]）
- 长度守卫（`tds.length < 8` → `< 9`）

改完 grep 全部 `tds[` 逐一核对，漏一处 = 该交互静默错位（菜单带错参数/状态写错列），浏览器不报错。

## 演示铁律
- 状态切换只原地变色（badge 换 class），**禁止重排序/沉底**（用户要现场演示开关效果）
- 造 10+ 条混合四态的演示数据（贴合当前客户业务场景，如党建问题），让批量选择效果直观

## ⚠️ 批量按钮类型敏感判断（2026-09-02 申请上屏页用户明确纠正）
批量操作按钮**不能只看「有无勾选」**，必须按勾选集合的状态类型精确判断：
```
勾选全部为「未上屏」→ 仅「批量上屏」可点
勾选全部为「已上屏」→ 仅「批量下屏」可点
混合勾选（含已上屏+未上屏）→ 两个按钮都禁用（浅色 disabled）
未勾选 → 都禁用
```
- 默认 `disabled` 浅色（`background:#f5f5f5; color:#bfbfbf; border-color:#d9d9d9; cursor:not-allowed`），条件满足才换成高亮（`primary`）
- 实现两层保障：
  1. **按钮层**：`updateBatchBtns()` 遍历勾选集合，全部 off → canOn=true；全部 on → canOff=true；混合 → 双 false
  2. **函数层兜底**：`selBatchOnScreen()` 内部再过滤 `!x.on`、`selBatchOffScreen()` 过滤 `x.on`，即使异常触发也不误操作（勾选的照片均已上屏时 toast 提示直接返回）
- 用户原话判据：「勾选的数据包含了上屏、未上屏两种 → 按钮还是浅色不可点；只有勾选了对的数据，对应按钮才能点」——**混合禁双、纯净亮单**，不要做「有勾选即全亮」的简化
