# B端界面 AI 设计图提示词模板

场景：羡阳觉得某个原型页面/弹窗丑 → 要求写一段提示词给外部 AI 设计工具（即梦/豆包/文心一格等）生成设计图。Hermes 只负责写提示词，不落地改代码；用户拿到设计图确认方向后，再走正常原型修改流程（Claude Code 执行）。

## 六段式结构（按顺序写，字段描述要具体）

1. **场景**：B端企业后台（XX 运营管理平台）+ 一句话功能定位
2. **入口与触发**：从哪个页面/哪个按钮打开，说明用户的决策上下文（在什么任务流程中操作）
3. **内容与字段**：逐字段列出并标注主次——"应最突出"/"次要信息"，不要平铺列表；核心决策字段单独强调
4. **交互要求**：核心决策点用什么控件（卡片/分段控件选中态）、显隐逻辑（未选中隐藏、选中平滑展开）、选中态视觉要明确
5. **视觉风格**：Ant Design 5 企业后台；主色 #1677ff、浅蓝高亮 #e6f4ff；白卡片底、浅灰分隔、圆角 6-8px；按钮右对齐（取消/确定）；禁渐变/大色块
6. **输出规格**：端与尺寸（PC 弹窗 560-600px）、需要哪几种状态（默认态/选中态等）

## 要点

- **先看现状再写提示词**：grep 目标弹窗/页面真实字段与交互（pages/_shared.html / 对应页面），不凭想象编字段
- 核心是让 AI 理解"用户在这个界面要做什么决定"，设计才有决策层级感
- 视觉偏好遵循用户既有约定（AntD5 蓝色系，hover/选中不用灰色）——见 visual-reference.md
- 提示词写成通用可投递形式（纯文本描述，不依赖某工具语法），用户可发给任意设计工具
