# Demo 真实素材获取与合规筛查

客户要「用真实相关的图片」时的完整流水线：找 → 核验 → 裁切 → 命名接入 → 登记口径 → 过筛。
原则：**一次下全（十几张）再挑**，别边下边接；缺图宁可明示缺图。

## 1. 找图

| 来源 | 适用 | 注意 |
|---|---|---|
| Wikimedia Commons | 现状照片（校园、建筑、街景） | 自由许可可商用**需署名**；国内直连常被墙，走本机代理 `127.0.0.1:10809`（urllib 显式 ProxyHandler / curl -x） |
| 公开图文报道、校友回忆文章（搜狐/澎湃/今日头条/地方媒体） | 历史照片（1940s–1990s 校门、建筑、活动） | 最有料的一类；用 `web_extract` 抓文章，**图 URL 与 alt 文本常按顺序对应年代**，一次拿全 |
| 客户官网（.edu.cn / icampus.cn 的 `wcm.files` 上传图） | 现状照片（客户自有素材，最安全） | 常是 2–4MB 大图，必须裁切压缩 |

- 搜狐图库 CDN（`5b0988e595225.cdn.sohucs.com`）URL 带 `q_70,c_zoom,w_640` 参数可直接下载，几十 KB 一张，正适合做卡片封面。
- `web_extract` 拿到的若是站内嵌页而非图片直链，改抓移动版（`m.<domain>`）通常能拿到直链。

## 2. 核验（必做，且要问对问题）

- 每张下完**先用 vision 过一遍再入项目**。问法要能抓到风险，不要只问「这是什么」——
  **「画面里有没有政治标语、领袖像、口号文字？主体是什么？」** 只问「这是什么」问不出标语。
- 用途匹配也要核：想当「某年代校门」就要能确认年代特征（黑白/彩色、门柱文字、周边建筑）。
- **政治敏感素材排除清单**（公办学校 / 党政客户项目）：
  - 带特定历史时期标语、领袖像的老照片 → 不用
  - 铭文含民国纪年、当时政界人士署名的碑刻/实物 → 不用
  - 拿不准的年代争议画面 → 不放，宁可缺图
- **素材与叙事要对得上**：奠基碑 ≠ 建校物证；不要用一块碑去证明建校年份。
- 缺图时在界面上**明示缺图**（斜纹占位 + 「那个年代没有留下照片」），比配错图或配现代图专业。

## 3. 裁切与命名

- PIL 统一裁到固定比例（卡片封面 600×400 ≈ 1.5:1），按**用途**命名并配套 CSS 类：
  `cover-*`（首页/列表卡）、`banner-*`（详情横幅）、`thumb-*`、`hero-*`（首页背景）、其余按内容命名（`era-1997-gate` / `story-festival` / `timeline-1970s`）。
- shell 里一行一个背景类：`.era-1997-gate { background-image: url('../assets/era-1997-gate.jpg'); }`，页面只写类名。
- 路径必须 `../assets/`（dist 与 assets 同在 `prototype/` 下，本地才能打开）；`publish-preview.sh` 发布时自动重写为 `assets/`。
- **原图留在 `素材原图/`，不进 assets**（不参与发布），便于后续换图；按来源分目录（`素材原图/官网/`、`素材原图/<媒体名>/`）。

## 4. 登记与口径

- README 固定两节：
  1. **图片来源与许可**：表 = 文件 / 原始文件 / 作者 / 许可。
  2. **⚠️ 主动排除的素材（原因 + 勿擅自加回）**：把排除项写成表，避免后来者「好心」加回去。
- POC 演示阶段：客户自有素材（Logo / 校徽 / 校内照片）可直接用；**正式对外发布仍需客户确认授权与署名口径**。
- 事实性文案（校史年份、人物、数字）一律标注「公开资料整理稿，正式发布前须客户核定」。
