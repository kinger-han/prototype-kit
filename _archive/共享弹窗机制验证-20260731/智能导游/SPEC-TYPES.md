# Spec 类型模板

每条标注的 `spec` 结构由 `type` 决定。以下是 8 种 type 的模板。

---

## page（页面级）

```json
"spec": {
  "职责": "页面干什么",
  "初始化": "进入时调什么接口",
  "权限": "谁能访问 / 无权限怎么处理",
  "离开": "离开是否需要确认"
}
```

**必填字段**：职责、初始化

---

## button（按钮）

```json
"spec": {
  "作用": "按钮干什么",
  "flow": [
    { "do": "validate", "target": "校验什么" },
    { "do": "request", "api": "接口地址" },
    { "do": "success", "then": [
        { "do": "toast", "message": "提示文案" },
        { "do": "refresh", "target": "刷新目标" },
        { "do": "close", "target": "关闭目标" }
    ]},
    { "do": "error", "then": [
        { "do": "toast", "message": "{errorMessage}" },
        { "do": "preserve", "target": "保留数据" }
    ]}
  ],
  "boundary": ["边界条件"],
  "exceptions": ["异常处理（覆盖默认规范才写）"]
}
```

**必填字段**：作用、flow

**可用 do 动词**：open / close / validate / request / success / error / toast / refresh / preserve / confirm / navigate / reset

---

## input（输入框 / 选择器）

```json
"spec": {
  "作用": "收集什么数据",
  "必填": true,
  "规则": ["格式/长度/范围校验"],
  "默认值": "无 / 具体值",
  "失焦": "失焦行为",
  "错误提示": "校验失败提示文案",
  "校验": {
    "规则": "描述",
    "example": { "pass": "13800138000", "fail": ["123", "abc"] }
  }
}
```

**必填字段**：作用、必填、规则

---

## list（列表 / 表格）

```json
"spec": {
  "数据来源": "GET /xxx",
  "排序": "默认排序",
  "分页": "每页20 / 滚动加载 / 分页器",
  "筛选": "支持的筛选条件",
  "空状态": "无数据显示什么",
  "刷新": "何时刷新"
}
```

**必填字段**：数据来源、分页、空状态

---

## state（状态字段）

```json
"spec": {
  "作用": "状态表示什么",
  "枚举": {
    "0": { "label": "待处理", "可操作": ["编辑","删除"],
           "example": { "status": 0, "可见按钮": ["编辑","删除"] } },
    "1": { "label": "已完成", "可操作": ["查看"] }
  },
  "迁移": [
    { "from": "0", "to": "1", "trigger": "点击完成" }
  ],
  "不可逆": ["1"]
}
```

**必填字段**：作用、枚举、迁移

---

## computed（计算字段）

```json
"spec": {
  "作用": "计算什么",
  "公式": {
    "表达式": "price * count - coupon",
    "example": { "输入": {"price":100,"count":2,"coupon":30}, "输出": 170 }
  },
  "依赖": ["price","count","coupon"],
  "更新时机": "任一依赖变化立即重算",
  "边界": ["最小值0","最大500"]
}
```

**必填字段**：作用、公式、依赖

---

## modal（弹窗 / 抽屉 / 确认框）

```json
"spec": {
  "触发": "什么操作打开",
  "内容来源": "数据从哪来",
  "确认结果": "点确认做什么",
  "取消结果": "点取消做什么",
  "关闭行为": "点X/遮罩关闭，数据保留还是清空"
}
```

**必填字段**：触发、确认结果、关闭行为

---

## linkage（联动）

```json
"spec": {
  "触发源": "哪个元素触发",
  "条件": "什么条件触发",
  "联动目标": "影响哪个元素",
  "联动结果": "目标变成什么样"
}
```

**必填字段**：触发源、联动目标、联动结果
