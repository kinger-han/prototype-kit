# 智能导游 - 功能清单

---

## 一、移动端C端（游客小程序）

| 序号 | 模块 | 功能 | 功能描述 | 备注 |
|------|------|------|----------|------|
| 1 | 用户登录 | 扫码登录 | 扫描场馆二维码解析场所、客户参数，校验通过跳转导游对话页 | 二维码携带cid参数，区分客户场馆 |
| 2 | 用户登录 | 微信授权登录 | 勾选协议一键拉起微信授权，弹窗确认绑定手机号完成登录 | 手机号仅身份识别，无短信验证码；绑定后不可修改 |
| 3 | 用户登录 | 用户身份校验 | 凭手机号区分新老用户，新用户自动建档，老用户恢复当前场馆会话 | 一期仅单场馆互通，跨场馆历史数据隔离 |
| 4 | 用户资料 | 个人信息设置 | 首次登录自动拉取微信头像、昵称填充，性别默认空；拉取失败使用默认 | 仅展示，不支持修改手机号 |
| 5 | 用户资料 | 游客信息查看 | 展示自身昵称、脱敏手机号、头像、注册/活跃时间 | 仅C端游客自有信息，不含运营账号 |
| 6 | AI对话交互 | 开场引导语 | 进入对话页AI自动自我介绍并推送引导提问 | 话术后台运营可配置 |
| 7 | AI对话交互 | 快捷问题按钮 | 对话页固定3-4个高频问题，点击一键发起提问 | 问题内容运营后台配置 |
| 8 | AI对话交互 | 知识库问答 | 用户提问检索场馆专属知识库，输出展品、路线、便民类答复 | 按登录场馆路由隔离知识库数据 |
| 9 | AI对话交互 | 多轮上下文对话 | 携带历史对话实现连续追问，无需重复背景 | 携带5-8轮历史，最终轮数由开发调试确定 |
| 10 | AI对话交互 | AI意图澄清反问 | 用户意图模糊时主动反问，提供可选方向辅助确认需求 | 界面复用快捷按钮组件，独立于多轮对话能力 |
| 11 | AI对话交互 | 动态追问推荐 | 每条回答下方生成3个关联问题，点击直接发送提问 | 回答与追问一次性生成，减少接口调用；兜底回复不展示追问 |
| 12 | AI对话交互 | 语音转文字输入 | 长按麦克风录音，松开转文字发送，不上传原始语音 | 无声、识别失败、网络异常弹窗提示兜底 |
| 13 | AI对话交互 | 流式输出答复 | AI回答逐字实时展示，无需等待完整生成 | 优化等待体验 |
| 14 | AI对话交互 | 中断生成回答 | 回答加载中支持手动停止，已生成内容保留展示 | |
| 15 | AI对话交互 | 消息操作功能 | 单条回答支持复制、重新生成、语音朗读 | 语音播报默认不自动播放，音色固定不可配置 |
| 16 | AI对话交互 | 一期内容样式 | 对话回复仅展示文字+emoji，不支持图片 | 图文问答规划至二期 |
| 17 | AI对话交互 | 兜底回复机制 | 无知识库匹配/无关问题输出标准兜底话术，同步人工联系方式 | 触发自动记录问题、用户、场馆等数据，同步后台会话 |
| 18 | 会话管理 | 新建会话 | 用户登录自动创建全新空白会话 | |
| 19 | 会话管理 | 历史会话管理 | 侧边栏查看历史对话，支持切换续聊；会话数据保存90天 | 超90天会话自动清理 |

## 二、PC端管理后台

### 1. 用户管理

| 序号 | 功能 | 功能描述 | 备注 |
|------|------|----------|------|
| 20 | 筛选模块 | 支持按相关客户、状态、注册时间范围筛选用户。选择客户后联动其他筛选，查询按钮触发筛选，重置清空条件 | |
| 21 | 用户列表 | 展示用户列表信息，支持导出、搜索、分页。字段：手机号、昵称、相关客户、总会话数、最近访问时间、注册时间、状态、操作 | |
| 22 | 导出按钮 | 导出用户数据，支持按客户、用户状态、时间范围筛选导出内容 | 一期不做，二期实现 |
| 23 | 操作列 | 每行数据末尾的操作按钮组：详情（打开详情弹窗）、禁用/启用（禁用需二次确认） | |
| 24 | 用户详情弹窗 | 查看用户详细信息，包含三个标签页：基本信息、关联场馆、会话记录 | |
| 25 | 禁用确认弹窗 | 确认是否禁用指定用户，确认后执行禁用，取消则不执行 | |

| 28 | 场馆列表 | 展示所有场馆信息。字段：所属客户、场馆名称、二维码（缩略图预览）、扫码次数、智能体、知识库、状态、创建时间、操作 | |
| 29 | 导出按钮 | 导出场馆数据，支持按客户筛选导出范围 | 一期不做，二期实现 |
| 30 | 操作列 | 每行场馆数据的操作按钮组：详情、编辑、停用/启用、删除 | |
| 31 | 场馆详情弹窗 | 查看场馆详细信息：所属客户、场馆名称、状态、智能体、创建时间、备注、二维码预览 | |

## 三、全局规则

| 规则 | 说明 |
|------|------|
| 客户-场馆从属关系 | 必须先选择客户，才能选择该客户名下的场馆 |
| 删除二次确认 | 所有删除类操作必须弹出二次确认，不允许一键直接删除 |
| 会话质量分级 | 优质（兜底=0）、一般（1≤兜底≤3）、需关注（兜底>3） |
| 二维码自动生成 | 新增场馆保存后自动生成二维码，列表不显示未生成状态 |
| 会话数据保留 | 会话数据保存90天，超90天自动隐藏 |
| 知识库路由隔离 | 按登录场馆路由隔离知识库数据，一期仅单场馆互通 |
