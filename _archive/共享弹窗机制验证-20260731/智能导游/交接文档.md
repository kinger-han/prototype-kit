## 三、踩坑点（必须记住）

### 3.1 build.py 占位符会打断路由注入

**问题**：在 shell 模板中放 `<!-- ANNOTATION_INJECT_BODY -->` 占位符 → 路由代码注入失败 → 整个原型瘫痪。

**原因**：build.py 靠 `shell.replace('</script>\n</body>', wrapJs)` 注入路由代码，占位符打断了这个字符串匹配。

**正确做法**：用 `</head>` 和 `</body>` 替换插入标注 CSS/JS，不依赖占位符。

### 3.2 dist 补丁每次 build 后丢失

弹窗 HTML、CSS 补丁、问候语修改在 dist 层，build 会覆盖。每次 rebuild 后需重新打补丁。

**应迁入 shell 模板但还没做。**

### 3.3 JS 花括号不平衡 = 全页面瘫痪

修改 `<script>` 后如果花括号 `{}` 或圆括号 `()` 不平衡，整个 script 块解析失败，所有 JS 功能失效。症状："页面能打开但点啥都没反应"——最隐蔽的 bug。

**必须检查**：
```python
import re
scripts = re.findall(r'<script>(.*?)</script>', content, re.DOTALL)
for s in scripts:
    assert s.count("{") == s.count("}")
    assert s.count("(") == s.count(")")
```

### 3.4 标注编号必须每页独立从 01 开始

badge 只显示序号部分（如 `kb-01` 显示 `01`），key 加页面前缀避免冲突。修改编号时不要重写 content 字段。

### 3.5 annotation.js 函数定义必须在使用之前

在 IIFE 中，如果在 `renderToolbar()` 内部定义 `updateListBtnCount()` 然后在 `renderAllBadges()` 调用它 → ReferenceError → 整个 IIFE 中断。

### 3.6 Python 写 JS 时 `\u` 会被双重转义

在 Python 脚本中生成包含 `\n` 的 JavaScript 字符串时，需要特别注意转义问题。
